## Corrections

- Web and mobile setup begins with compact choices and expands for configuration. Back stays in the header; completion actions scroll with the form. Model-loading text remains centered independently of its icon.
- Native workspace keeps its header, mode controls and safe-area padding stable during keyboard presentation. Setup uses native scrolling keyboard insets; existing pageSheet detents change without remounting the form. Other sheets cache geometry before keyboard animation.
- Web popups share Radix focus trapping, Escape dismissal, background scroll locking and focus restoration. Initial popup focus does not summon the software keyboard. Nested help closes before Settings. Local speech selects have explicit accessible names.
- Web camera reports permission errors with retry, disables capture until preview data exists, keeps Close above the loading overlay, and releases streams returned after dismissal. Video attachment also handles the modal portal mounting after a media request resolves.
- Native image preview reserves a 44pt close target beside a flexible heading. Heading scaling is capped at 2× to retain image space, as for other sheet titles. An opaque backdrop prevents large underlying text from bleeding through. Overlay labels follow image geometry rather than Dynamic Type, matching Web's image-relative rendering.

## Platform impact

- **Web:** setup layout, model button alignment, popup interaction/accessibility and camera failure handling.

- **Tests:** setup geometry and UI coverage at 390×844 and 320×720 in both themes, desktop 1440px, all Settings sections, popup keyboard behavior and camera lifecycle. Native matrix includes keyboard appearance/dismissal, speech settings and optional setup steps.
