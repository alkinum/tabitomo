# 功能与 UI 总体复核（2026-09-21）

检查覆盖 Web、Expo、shared core 与原生适配：翻译 / Explain / Q&A、语言与输入方式切换、录音、OCR / Vision、注音、复制 / 朗读、首次配置、模型发现、设置草稿、加密配置、二维码、离线模型和安全区。使用合成 provider 测试请求与失败恢复，没有调用用户的付费 AI 服务。

## 修复

| 发现 | 修复与验证 |
| --- | --- |
| Web 改语言后 debounce 和旧请求仍可写回，保存新模型仍可复用旧模型缓存 | 统一取消工作台请求，改语言清理旧输出，配置变化清空缓存；真实浏览器延迟响应与模型切换回归 |
| Web 图片处理失败会删除照片，换图读文件期间可回写旧上下文 | 保留照片供重试，清理旧结果，按选图代次忽略迟到任务；OCR 503 → 原图重试回归 |
| Web 麦克风授权迟到、停止录音时最终文本尚未返回，媒体轨道等待云服务后才释放 | 录音按会话隔离，预检查语音连接，及时释放媒体轨道；Web Speech 等最终事件后翻译，保留实际录音 MIME；权限延迟 / final transcript 回归 |
| Web 没有停止朗读操作，复制失败无提示 | Play / Stop 状态、结果变化停止朗读，复制错误 toast 与按结果重置反馈 |
| 首次配置的二维码扫描没有相机容器，关闭流程未释放摄像头 | 增加稳定容器与生命周期隔离；Chromium 合成摄像头验证启动、关闭与轨道释放 |
| 首次手动配置保存失败无反馈，部分字段无关联标签 | 保留草稿并显示保存错误，连接字段统一命名并关联 label；存储失败回归 |
| 生产版日文注音模块加载失败，且服务器自动解压时重复解压字典 | 修正旧 zlibjs 的 CJS 导出绑定，字典加载兼容 gzip 和已解压字节；实际 production bundle 与真实字典生成 ruby 回归 |
| 注音异步结果可覆盖后续内容，HTML 直接渲染源文本 | 丢弃过期注音任务，输入与失败 fallback 都转义；真实字典和失败路径验证 HTML 保持字面文本 |
| 全量 lint 失败 | 配置 Node 脚本 / Expo CommonJS / 图片 require 的实际运行环境，清理无用声明；自动翻译 effect 使用最新事件回调，保留现有依赖触发语义 |
| 原生最大 Dynamic Type 下品牌换行、固定导航和通知把输入区挤出屏幕，键盘打开后未露出输入框 | 品牌缩放上限 1.3、导航标题上限 2；正文 / 输入 / 操作仍跟随系统字号。大字号导航与通知移入可滚动工作区，模式使用横向标签并自动露出当前选项，语言与面板标题纵向布局；聚焦并打开键盘后按实际布局滚动到输入框 |

## 平台与契约

- Web：上述生命周期、失败恢复、语音、注音、首次配置与表单语义修复。
- Mobile：对照并回归既有等价行为；修复最大字号的工作区可达性。清理无用代码，自动翻译定时任务通过 React Effect Event 读取最新回调，模型选择 memo 明确依赖草稿。
- Shared core：本轮未改变设置字段、默认值、provider 格式、加密格式、语言覆盖或业务决策。
- Native：未改变 Swift / ObjC bridge、entitlement 或 CloudKit 同步协议；保留原生 pageSheet、系统开关、安全区与键盘避让。
- Tests：新增 `workspace-recovery.spec.ts` 与首次配置扫码回归，扩充 parity 锚点；同时执行现有 core、Expo、浏览器与 iOS simulator 检查。
